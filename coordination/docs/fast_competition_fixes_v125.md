# v1.25：随机地图生成修复与红色新鲜观测

2026-10-05，北京时间。目标仍是六机实际运动、600仿真秒内裁判6/6且无建筑接触。上一版三轮预算已经结束，8159结果4/6，剩白色和一个红色。本版尚未物理验收；用户随后授权两天自主继续，每5.5小时唤醒，每次最多一轮，使用独立预算，不改写旧三轮结果。

## 本次实现

- 隔离地图生成副本中，原生成器第十次尝试的EOF回退会写出空world。改成明确报CITY_PLACEMENT_EXHAUSTED并在已有生成尝试预算内换种子，不把失败随机布局与旧建筑拼接。原官方文件保持只读。失败种子860915现被明确拒绝，860916生成有效场景；这是地图生成检查，没有启动额外物理仿真。
- 红色遵循用户转述赛事组口径：只上报red和坐标，开发裁判与任意剩余红色真值匹配。red1/red2仅内部轨迹槽，不是官方身份。没有修改消除时长、精度、裁判阈值。
- PR_FAST_RED_PERSON=1时，同一原图人体重合与红色衣服验证通过，连续三张不同原图命中、本帧实际命中、原图年龄不超过1秒，允许沿用绿白的新鲜观测通道，越过静止/附着拒发。其他几何、距离、置信度、上报原图去重仍有效。未获人体衣服证明的红色保留原策略，不给予此豁免。蓝色和棕色保持原策略。
- 视觉CSV尾部追加person_frame_verified/person_hits/track_miss/fresh_person_allowed，拒发事件带同样证明，避免仅凭“看见目标”判断连续上报。
- 既有单轮入口增加--single-seed，独立最大一次预算；仍使用原启动、接触观察和限定进程收尾。没有另建测试框架。
- 上版已提交的同机失败任务重试限制、绿白每次追踪计数修复将一同进入新六机快照；此前尚未物理验证。
