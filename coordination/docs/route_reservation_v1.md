# 实际水平路线预约 v1（2026-10-03 冻结）

## 2026-10-07兼容修订v1.4：搜索卡点的有界退出

offer/grant/reservations仍为schema_version=1，字段集合不变。搜索任务完成起飞后，双来源新鲜三维实测速度各自连续1秒不超过0.15米/秒，且已发水平命令为零，才可提议退出。正常规划半径仍1.2米；候选退出网格为0.9米，两种网格使用同一观测快照和友机/保留通道排除。近期实际命中构成起点膨胀阻塞时，候选必须从真实位置连接到正常网格自由终点，全段远离这些命中，最多2米。未知和较小包络内占用不构成放行理由。

取得当前同代次、匹配offer及完整points的实际grant，并再次验证停稳资格后才启用较小执行包络。每代次最多一次，路线续约不能重置额度、时间或实测累计运动距离。最终水平指令上限0.3米/秒且不朝阻塞命中移动；执行最长15秒、接受自身位置样本累计路径不超过2米。当前扫描的双来源实测制动、原1.2米雷达保护、友机和路线门均继续检查。退出期间使用授予时本地高度，移动XY用PZ保持，停止用XYZ保持；显式升降及限高紧急动作仍优先。

STOP、任务/路线到期、新代次、定位/变换/地图epoch异常及执行预算耗尽撤销退出；撤销只停止本机执行例外，不释放manager保留占用。到达退出末点附近且当前正常1.2米包络净空通过后停止退出，下一拍继续原搜索任务。退出不算有效观察，也不完成搜索点。有效退出期间不以每秒搜索刷新取消其在途路线。

通用默认关闭，city入口默认开启，可用CITY_BOUNDED_ESCAPE=0回退；六agent统一含bounded_escape.py、online_radar_planner.py、position_brake.py的新快照。旧manager线格式兼容，旧agent没有退出行为。导航schema1新增可选bounded_escape诊断，含代次、offer、开始/扫描时刻、包络、限速、实测运动距离和保持高度；不是新增授权来源。实体效果尚未验证，不能称建筑接触或全部卡点已解决。

## 2026-10-06兼容修订v1.3：盘旋规划长度与方向

线格式继续schema_version=1，授权、STOP、到期、退役及保留占用语义沿用v1.2。新增本地配置`SWARM_ORBIT_PLAN_CHORD_M`，有限且在0..16米，通用默认0表示原0.2弧度步长；city入口设置9米。8米观察环与4米执行引导不变。长规划终点只进入现有在线规划/offer/grant链，不授予直飞环上点的权限；路径被未知空间截短或遇转角时仍减速。

两个候选终点仍在8米环上。优先比较新鲜velocity_local及已接受自身差分两个方向的最差角度一致性；两者均低于现有0.15米/秒停稳门限或缺失时，才参考当前新鲜视觉目标的估计运动方向；无方向则确定性选原正向。该选择只提出下一规划点，不预测/生成视觉坐标或时间。实测来源缺失仍由执行门停车，不能靠目标速度代替自身实测。

city_control_config新增`orbit_planning_revision`、`orbit_radius_m`、`orbit_plan_chord_m`和`orbit_direction_selection`诊断。六机统一含`orbit_geometry.py`的新快照；旧manager线格式兼容，旧agent仍有短步长行为。搜索3/追踪2.6米每秒、增益0.8、制动与各门限不变。597项离线检查通过，v1.38尚未实体执行；v1.37本轮完整600秒为4/6、非地面接触0。详见[实现、验证范围及接入](fast_competition_fixes_v138.md)。

## 2026-10-06兼容修订v1.2：请求沿最新路线，实测可在保留占用内刹停

线格式仍schema_version=1，offer/grant/reservations字段集合不变。请求运动、引导直连和停止段选速仍受当前已经提交、同任务代次且未过期的grant.points约束。velocity_local和已接受自身位姿差分两个实测停止段，除当前折线外，可以使用实际`/swarm/route_reservations`中本机、同运行、同代次的保留segments；快照须单调新序号且接收年龄0..1.5秒（现有规划输入预算）。不使用友机segments作为自己的刹停空间。

快照缺失、过期、代次不符或本机被明确移除时，只检查最新折线；非法/重放消息不刷新时效。当前grant仍须有效，保留快照不能代替任务或路线授权，也不能重新执行旧任务。STOP、路线/任务到期、旧运行/旧代次和定位隔离仍阻断运动。管理器原保留占用、STOPPED/退役/真实退出规则不变；本次不清除任何旧路线。

0.75米包络、0.1米采样和0.70米判定阈值不变。地图、雷达、友机和两个实测方向仍分别复核。内部查询在某真实线段已容纳采样点时提前结束；失败点仍计算完整集合的精确最近距离。导航schema1可选诊断增加`route_check.measured_envelope`（CURRENT/CURRENT_AND_RETAINED）及`retained_snapshot_seq`；不把它们当作外部授权字段。

## 2026-10-06兼容修订v1.1：路线内选速与pending续约（实测范围以v1.2为准）

线格式仍schema_version=1，offer/grant/reservations字段集合不变。等待同代次新offer时，agent可以续当前已经提交且points完全相同的旧offer；续约不提交pending路径。新offer匹配请求、代次和实际points后原子提交，随后旧offer不能续回。STOP、过期任务、旧代次、旧序号与旧运行继续拒绝。manager与六agent统一快照；旧manager线格式兼容，旧agent缺少此执行修复。

地图允许的引导直线同时必须位于当前已授折线包络内。执行器在加速度限幅前、最终发布前沿请求方向选较低速度，使请求停止段仍位于原0.75米包络（0.1米采样使用0.70米阈值）。不扩大包络、改向或忽略未知/障碍/友机。velocity_local与自身差分两个实测方向分别检查；任何实测停止段越界都停车，不能用缩小请求解释为实测已可刹住。长直线仍可用当前3米/秒搜索配置；没有新增统一1米/秒限速。极小可行速度不足0.05米/秒时保持XYZ停止，避免无效运动脉冲。

内部折线检查缓存只合并共线重叠线段的精确集合，保留原grant.points及全部原预约；不是删掉旧任务占用。导航日志schema1增补requested_xy、route_state（offer/generation/expiry/points）、route_velocity_evidence（限幅前/最终判定）及route_check。这些仅用于取证，不是新增授权字段，线上阻塞反馈schema1保持。

v1.36候选离线565项通过；已执行v1.35的完整600秒为3/6、建筑接触0，不能将候选回调/几何检查当新的实体结果。详见fast_competition_fixes_v136.md。

任务授权 v2 保持兼容。新增 String JSON 话题 `/swarm/route_offer` 和 `/swarm/route_grant`，schema_version=1，使用相同 run_id。offer 含 uav_id、generation、offer_id（逐机规划请求号）、points（实际规划后的世界 ENU XY 折线，包含实测起点）。grant 含上述标识、seq、expires_s、points。实际 agent 仅执行与当前任务代次和本地待提交规划请求一致的 grant；旧运行、旧请求和旧序号不能提交路径。

单写者 manager 串行检查完整机队的新鲜实测运动状态（0.5s），起点距自身实测位置不得超过 0.75m；折线须有限、2..2048点。整条折线与其他飞机的保留折线及当前位置间距必须大于 6m（4.5m保护距离加两机各0.75m跟踪包络）。同一任务代次的重规划原子加入原预约并保留旧折线，不能凭新路径或预计时间删除旧占用；冲突请求拒绝但不撤销已授路线。

规划输入话题 `/swarm/route_reservations`（String JSON）含 schema_version=1、run_id、seq（manager单调递增）、reservations={uid: {generation, segments}}。它描述全部保留折线，空集合也显式广播；不因授权过期移除。agent严格校验序号、成员与有限线段，并在规划时结合新鲜友机位置阻挡其他飞机的6m预约包络。此快照用于生成候选，不能代替manager串行授予；并发候选可能冲突，拒绝后最多每1s重新规划。旧任务已验证停稳后快照才移除其折线，友机位置占用仍保留。

任务 STOP / 到期停止路线续约，路线授权1.2s到期只停止执行，保留预约。只有任务授权核心已验证该代次 STOPPED（连续1s实测停稳且永久停止旧任务执行）才能将旧路线降为原机实测位置占用；随后所有放行仍检查完整机队的新鲜位置。缺状态/失联不证明空域清空。原任务目标锁的 RETIRED/退出流程不变。

最终速度发布同时受任务门、雷达、友机保护和路线门限制。请求停止段位于最新已授折线0.75m包络内，实测停止段可按v1.2使用新鲜的同机同代次保留折线；路线过期、旧代次或超出相应包络均停止水平命令，保持OFFBOARD流。不能以局部ORCA侧移、盘旋或直飞兜底越过路线门。规划器仍负责障碍净空；本接口不以路线预约替代地图证据。

本版为保守空间预约，不作预计时间自动释放，也不声称完成三维起降、全拓扑脱困或分布式一致性。同代次累计预约可能降低吞吐；等待时保留已知位置，不猜安全让行点。参数是开发配置，不能据此认定正式比赛通过。
# 2026-10-03 停稳刷新补充（线格式不变）

同代次保留路线会随重规划增长。实际manager每30秒允许一架持有路线的飞机进入任务STOP，待核心实测连续停稳1秒并永久封锁旧代次，才撤去旧路线，再以新任务代次重领原任务和提交新路线。刷新不是TTL清占用；失联、缺停稳样本仍保留旧路线。目标唯一锁在整个停稳/重授予期间保留同一持有者。一次只刷新一机，避免全部飞机同时暂停；当前停稳位置仍参与其余飞机的路线冲突检查。该策略减少历史路线累积，不证明全部死锁可解。
