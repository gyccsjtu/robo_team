# 实际水平路线预约 v1（2026-10-03 冻结）

任务授权 v2 保持兼容。新增 String JSON 话题 `/swarm/route_offer` 和 `/swarm/route_grant`，schema_version=1，使用相同 run_id。offer 含 uav_id、generation、offer_id（逐机规划请求号）、points（实际规划后的世界 ENU XY 折线，包含实测起点）。grant 含上述标识、seq、expires_s、points。实际 agent 仅执行与当前任务代次和本地待提交规划请求一致的 grant；旧运行、旧请求和旧序号不能提交路径。

单写者 manager 串行检查完整机队的新鲜实测运动状态（0.5s），起点距自身实测位置不得超过 0.75m；折线须有限、2..2048点。整条折线与其他飞机的保留折线及当前位置间距必须大于 6m（4.5m保护距离加两机各0.75m跟踪包络）。同一任务代次的重规划原子加入原预约并保留旧折线，不能凭新路径或预计时间删除旧占用；冲突请求拒绝但不撤销已授路线。

规划输入话题 `/swarm/route_reservations`（String JSON）含 schema_version=1、run_id、seq（manager单调递增）、reservations={uid: {generation, segments}}。它描述全部保留折线，空集合也显式广播；不因授权过期移除。agent严格校验序号、成员与有限线段，并在规划时结合新鲜友机位置阻挡其他飞机的6m预约包络。此快照用于生成候选，不能代替manager串行授予；并发候选可能冲突，拒绝后最多每1s重新规划。旧任务已验证停稳后快照才移除其折线，友机位置占用仍保留。

任务 STOP / 到期停止路线续约，路线授权1.2s到期只停止执行，保留预约。只有任务授权核心已验证该代次 STOPPED（连续1s实测停稳且永久停止旧任务执行）才能将旧路线降为原机实测位置占用；随后所有放行仍检查完整机队的新鲜位置。缺状态/失联不证明空域清空。原任务目标锁的 RETIRED/退出流程不变。

最终速度发布同时受任务门、雷达、友机保护和路线门限制。请求与实测速度的停止段都必须位于已授折线0.75m包络内；路线过期、旧代次或超包络均停止水平命令，保持OFFBOARD流。不能以局部ORCA侧移、盘旋或直飞兜底越过路线门。规划器仍负责障碍净空；本接口不以路线预约替代地图证据。

本版为保守空间预约，不作预计时间自动释放，也不声称完成三维起降、全拓扑脱困或分布式一致性。同代次累计预约可能降低吞吐；等待时保留已知位置，不猜安全让行点。参数是开发配置，不能据此认定正式比赛通过。
# 2026-10-03 停稳刷新补充（线格式不变）

同代次保留路线会随重规划增长。实际manager每30秒允许一架持有路线的飞机进入任务STOP，待核心实测连续停稳1秒并永久封锁旧代次，才撤去旧路线，再以新任务代次重领原任务和提交新路线。刷新不是TTL清占用；失联、缺停稳样本仍保留旧路线。目标唯一锁在整个停稳/重授予期间保留同一持有者。一次只刷新一机，避免全部飞机同时暂停；当前停稳位置仍参与其余飞机的路线冲突检查。该策略减少历史路线累积，不证明全部死锁可解。
