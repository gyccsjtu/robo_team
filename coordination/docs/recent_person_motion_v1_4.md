# 城市人物运动证据 v1.4

共享GPU六机轮中，uav_4将停着的路边车辆标为green并持续上报。
诊断图位于工作区tmp/shared_gpu_uav4_view.png；运行记录中的绿色坐标
约(48,7.5)，不能将其当作真实绿色演员坐标。
旧判据允许max_disp超过2.5m后终身保留运动资格，初期投影抖动可以触发此条件。

城市配置现在启用PR_RECENT_MOTION_WINDOW=4.0：以最近4秒真实图像测量的世界
坐标做线性拟合，至少需要1秒跨度，最新测量不超过1秒；沿用0.15m/s运动门限。
预测/coast不添加样本，不累积运动证据。非城市入口默认关闭，保留原兼容行为。

这仍是人物筛选启发式，不能证明不会误检。真实人物停住较久或短窗口往返可能
被拒，需在实际演员轨迹上验证。该变更不修改相机、雷达、权重或官方连续15秒判据。
