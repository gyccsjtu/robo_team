# 拍卖候选几何筛查 v1（冻结）

纯Python `screen_leg(start,end,peer_positions,peer_legs,separation=4.5)` 返回bool。输入为水平共享ENU米坐标；无效/非有限输入、途经友机位置、与友机已有或本轮选中任务直线段间距≤4.5m均拒绝。纯TaskAllocator接口增加可选 `candidate_filter(uid,cell_key,already_assigned)`，在改变格owner/承诺可见域之前筛查；旧独立调用不传filter保持兼容。

实际manager默认启用筛查，输入完整新鲜机队的位置、仍在执行的搜索格目标及本轮已选任务目标。目标使用manager修复后的可达代表点，不使用建筑内格中心替代。没有可接受候选时保留任务/锁现有语义，不猜测等待点，不把被拒任务提交到allocator。

这是分配阶段的保守启发式筛查：直线段不等于A*最终路线，友机跟踪/盘旋路线和退役占用也尚未纳入。因此它不构成几何预约或路径执行授权，不能声称已证明完整路径安全。运动接口v1的最终友机制动与任务授权v2继续有效。改变放行阈值须更新此说明和边界测试，4.5m属于原型配置而非比赛规则数值。
