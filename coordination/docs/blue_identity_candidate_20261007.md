# 蓝色运动身份候选与实际限制

基于blue_candidate_identity_plan及第二轮记录，已实现默认关闭PR_BLUE_IDENTITY_GUARD，city启用下一轮候选。没有修改运行中的仿真，也没有新起轮。

纯MotionIdentity只读实际原图世界坐标：4秒窗口、至少3张原图、至少2秒跨度、净位移2.5米，线性拟合RMS≤0.6米后建立身份。保持新原图时允许人物停住；原图超过1秒不能放行，断流>1.5秒或大跳变清除身份。实际Track init/update/verdict已接入；其他颜色、身高/净空/评分/附着验证保持，不删未确认候选。新CSV写original_s及raw_target_x/y和身份状态，以便下轮精确回放，而不是从发布框猜测实际更新。
