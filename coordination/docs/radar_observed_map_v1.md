# 雷达观测地图 v1

实际agent发布 `/uav_id/radar_observed_map`（nav_msgs/OccupancyGrid），水平共享ENU frame=`map`，原点/分辨率/尺寸来自规划范围元数据，仅复用范围，不读取其中障碍栅格。data=-1未知、0射线观测自由、100射线末端障碍。header.seq为地图观测版本，stamp为实际scan传感器时间。逐机话题隔离，不能以相同frame名称推断地图融合已完成。

纯Python核心按真实射线采样自由段，障碍端点在同帧自由证据上优先；无回波(+inf)只观测到range_max，无效波束不贡献证据。近距离盲区和量程外均不填成自由圆盘。位姿与scan时间偏差超过0.1s、scan超过0.5s/未来/倒序时拒绝；超过3s没有新射线证据的格恢复为未知，不据障碍消失直接认定自由。只发布二维观测，不证明三维净空。

该阶段地图尚作为实际雷达输入的证据与后续规划接入源，agent当前路径仍使用旧存储地图；不能称已经实现自主在线规划或随机比赛建图验收。后续必须使未知区域阻挡路径，并实现可达前沿探索及版本失效处理，避免把这张地图作为装饰性输出。

`info.map_load_time`标识本次局部->世界偏移对应的地图epoch；偏移变化会丢弃旧观测并重新建图。当前投影仅用yaw，未补偿roll/pitch，亦未记录高度分层；必须先补齐这些边界再将该证据用于严格路径放行。输出是栅格观测近似，不是自由体积证明。

实测：`validation/six_search_run08/` 保存60s实际六机manager/agent飞行及源码快照。六机均发布frame=map的新鲜栅格，最后版本118/119，未知格7435..9616（部分机7730/8467/8714/9323）、自由格2928..5109；空场景本轮障碍格为0，真实障碍回波建图仍需非空场景复验，不能用此轮替代。最小真实采样间距5.43m、最高4.99m，无提前完成消息，正式比赛false。

5项纯逻辑测试通过：射线自由/障碍/离线未知、无回波不填自由圆盘、过期恢复未知、时序不匹配拒绝、同帧障碍优先。全套241项测试238通过、3项既有基线错误。
