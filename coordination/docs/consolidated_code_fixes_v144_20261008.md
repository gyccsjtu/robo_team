## 本次新实现

OwnVisualGuidance只缓存本机实际confirmed原图的原始时间、世界点和同机拟合速度。1秒过期、重复/倒退/未来/非有限图拒绝，消除时清除。缓存不续原图时间、没有Publisher，不改变目标锁。_fly_companion和_control_tracking_navigation用它优先保持本机当前视野；没有本机新图时维持原有跨机接近、停控和有界重获。

agent把每相机运动估计放在全局新旧判定前；所以“不能倒退全局目标”不再同时等于“删除这架相机的新原图”。manager同样只保留该来源观测，全球目标点仍不倒退。实际任务授权、唯一setpoint发布者、友机/雷达/路线闸门继续执行。
