# 持续错误坐标：检测身份与投影的进一步区分

2026-10-08，实体执行143f8b1，未新开仿真、未修改产品代码。此前“身份/检测框/几何尚未区分”不够具体，本次用已记录的同原图相机姿态与检测框进一步核查。

## 目前查实到哪一步

最新13条估计距离≤22米的绿色原始检测都带person_frame_verified=true，且与真实绿色人物位置相差很大。11条具有同机、同原图时间的search_camera_frames元数据，能够按现有相机标定复算。

先把每个原始框底部像素投到地面，重建其候选世界坐标。11条最大复算差3.55e-15米，确认所用相机元数据、像素和原始检测记录一致，未错用另一架飞机或另一帧的数据。此数只是复算一致性，不是定位精度证明。

再将独立记录的真实绿色人物位置投回同一帧：使用人物中心垂直线上z=0、1、2三个点，仅用于离线核查，不输入控制。主要反例：

其他匹配样本同样不对应。分析依赖当前相机标定及位姿模型，未重建动画人物完整轮廓；不能据此辨认每个框到底是车辆、窗户还是树，也不解释所有历史上报。但多帧巨大横向差、部分人物在画面外/后方，与此前远处确有误差小于1米的绿色检测共同支持：**这批大误差中存在明显的错对象检测，不能只按“认对了人但距离偏差”处理。**

1号机多个错误绿色候选反复落在世界x约-35、y约-3至-1，而实际绿色人物在x约101至104、y约13至15。候选重复、坐标稳定，并不能证明身份正确。

## 为什么人体/颜色证明也没有挡住

person_frame_verified是检测器的一致判断，不是人工或裁判认证。当前PersonVerifier使用第二个person模型最低置信度0.1、两框IoU至少0.25；衣服判断在小框内统计颜色比例。两模型都可能把背景认成人，绿色背景也可能通过颜色门。当前证据确认“该证明可以误判”，尚未确认每个错误样本的具体person框、person置信度及背景物体，因为这些失败原图和支持框未被保存。

投影随后对任何通过门的框底部都假定落在世界z=0，并计算射线与地面的交点。**即使框不是人，数学上也能得到一个有限、连续、看起来合理的坐标。** 人体高度估计也依赖同一个地面假设，不能充作完全独立的身份证明。

这轮官方出口没有开启，错误坐标来自内部原始候选；仅一条棕色观测进入桥但未激活，不能把这些全部称为官方已错误播报。历史真正上传后的1至数米误差仍需分别检查脚点/遮挡、姿态时间对齐与融合补偿。

## 接下来针对根因修什么

先补有限的原始失败帧及同图两模型支持框、person置信度、IoU、衣服比例与脚点信息；当前记录只留下自定义框，无法知道person证明具体如何误判。原图和支持框必须一一对应，不使用事后图代替，不修改图像时间。

根据真实负样本修人体/颜色关联和模型误识别，再检查目标框底部是否确为脚点。若使用完整人体框修脚点，必须先验证它确实是当前同一人的框、未截断/遮挡，不能直接把任何匹配框当成可靠地面点。不能凭这里的反例立即统一提高阈值：那可能继续丢掉本来就很小的远处真人。

图像与位姿不同步、近水平射线敏感和遮挡导致脚点偏差仍是另一类候选根因，需要用认对人的样本单独验证。当前不能给所有错误一刀切改坐标偏移，也不重写双目来掩盖错对象问题。

同时保留已计划的远处合格线索→有界接近搜索，避免一直沿盲搜索路线错过真人。先修、离线检查、再决定物理轮；本次没有再次实跑，也没有宣称检测已修好。
