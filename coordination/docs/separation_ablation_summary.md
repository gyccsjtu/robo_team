# 编组内空间管理消融总结（n=40，6 目标，种子 1..40）

## 一句话结论

**搜索纵带相位错开（②）是最大杠杆：成功率 +27.5 点、目标级 +5.5 点、s-s 间距 4.8 倍改善；**
**局部排斥（③）只改善 s-s 类别、对全场间距几乎无益，且掉 5 点成功率 —— 可选。**
**最终推荐：`--space sepall`（SEP=3 + phase6 + fr1.5）或纯 ②（SEP=3 + phase6）。**

## 各层贡献拆解

- **① 编组几何分离（SEP_TARGET_M）**：编组内最小间距 0.003→0.10 m，代价 −1.3
  目标级点（见 [[robocup-sim-separation-tradeoff]]）。单独用反而掉成功率（55% vs 62.5%）。
- **② 搜索纵带相位错开（SEARCH_PHASE=6）**：**最大杠杆**。成功率 +27.5 点、
  目标级 +5.5 点、s-s 间距 4.8 倍。相位 4/6 是甜点，3 不够、5 次之（见
  [[robocup-sim-search-phase-offset]]）。
- **③ 局部排斥（FRIEND_SAFE）**：只改善 s-s 类别（0.129→0.376），对全场
  几乎无益（0.089→0.088），且掉 5 点成功率。**fr3 过强反而坏**（s-s 回落到
  0.039，排斥推出搜索带制造新擦肩）。fr1.5 是甜点（见 [[robocup-sim-repulsion-3]]）。

## 未达成

- **min_separation_m = 3.0 m 远未达到**（最好 0.088 m）。这是**规则层面的冲突**：
  15s 连续确认要求「合并观测拼连续」，而合并观测靠径向一字排开；把机推离射线
  就掉命中率（历史 60.5%→35.0%）。要同时满足需改观测几何，非调参能解。
