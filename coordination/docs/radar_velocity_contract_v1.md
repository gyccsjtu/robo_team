# 雷达速度保护接口 v1

2026-10-03 冻结。本接口用于本仓库 swarm_agent 的最终水平速度保护，独立于旧协同 JSON schema1；不改变 ROS 消息。纯 Python 返回结构含 `schema_version=1`、`velocity_xy`、`reason`、`clearance_m`。

输入：世界 ENU 请求速度与实测速度、机体 yaw、LaserScan 几何/距离数组、采样时间、当前仿真时间。位置姿态和实测速度在接入层检查新鲜性；扫描使用消息采样时间，不能用接收时间掩盖延迟。无帧、时间回退、过期、非法数据、覆盖不足输出水平零速及明确原因。正无穷允许表示量程内未命中；NaN、负无穷、低于最小量程不作为自由空间。

在实际速度方向和请求速度方向分别检查保护走廊，覆盖侧飞及后退。障碍按每束角宽扩张。请求速度只减小，不新增侧移或旋转方向；已测运动的停止距离不足时输出零速。扫描全周覆盖必须核验；量程之外不推断可飞。

停止距离为 `v * latency + v² / (2 * brake_accel)`。保护半径默认 1.2 m，延迟默认 0.5 s，制动加速度默认 0.5 m/s²，均为仿真开发参数，尚无本仓库飞行制动标定，不能宣称物理安全认证。允许速度由有效净空解反函数得到。

保护放在网格/边界恢复和普通加速度限幅之后、日志与最终 publish 之前，防止后级重新放大或改变保护指令。最终零速设定点不等同于飞机已经停下。零速也不自动释放任务或通道锁。

迁移：旧机头扇区转向保护由本接口替代；RADAR_GUARD=1 必须收到有效雷达与速度数据才允许水平运动。无雷达模式显式 RADAR_GUARD=0，仍是另一套待验收方案。保持原垂直控制，本接口仅声明水平扫描平面，不证明起降/完整三维净空。
