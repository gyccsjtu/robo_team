# 追踪导航兼容语义 v1（任务 schema2 / 路线 schema1）

官方裁判上传接入修订：内部red1/red2几何槽分别发布到`/actor_red1_info`与`/actor_red2_info`，payload均为`cls=red`，消息类型使用官方`ros_actor_cmd_pose_plugin_msgs/ActorInfo`。每条观测只上传到自身槽对应的一条话题，不复制广播猜测官方身份；官方两条回调均可匹配任一红色真值。旧`/actor_red_info`不是新版官方裁判订阅端点。上传观察器同步订阅两条官方话题，不能漏采红色证据。

2026-10-07。本修订定义本地追踪阶段，不新增线上字段，不改变任务授权、STOP、路线预约、视觉schema2及导航反馈schema1的解析方式。

`SWARM_TRACK_NAVIGATION_S`和`SWARM_TARGET_HOLD_S`在六机city候选中统一为8秒。通用默认仍关闭新行为。导航线索只能来自已接受实际视觉，缓存时间为该原图时间；查询、任务续约、融合外推和重复图不能刷新它。导航线索不构成实时观测，不计确认时间、不用于人物上报。

阶段为WAIT、CURRENT、APPROACH、REACQUIRE、FAILED、IDLE。授权消息可能先于实际视觉回调到达，此时WAIT停止XYZ等待原图，最多8秒，不允许仅凭派单坐标前进。CURRENT保持既有1.5秒实时引导上限，人物上报仍须既有1秒视觉门；超过实时引导时效但未超过8秒可走APPROACH，只向已观测净空、取得实际路线授权的观察位置前进。旧已提交路线仍指向人物旧坐标时停止等待观察位置的新路线，不沿旧路线越过观察距离。距最后观察位置约10米时停止XYZ，至多3秒有界朝向扫描；扫描不会延长8秒原图窗口。同代次重获至多一次，失败后的迟到原图不能自动取消失败。

新鲜实际观测恢复才回CURRENT。STOP、授权过期、代次/目标改变取消原阶段；FAILED发送现有TARGET_VISUAL_LOST追踪反馈，经既有6秒实测停稳及管理器STOP/占用退役后接替。清理管理器追踪字典不等于释放旧授权。白色与既有重获共享一次机会，第二次丢失不再重复开启扫描。

manager、六agent与新增tracking_navigation模块必须从统一快照运行。旧agent可解析原任务字段但仍会在1.5秒停止，不能把新manager与旧agent混用作为修复验收。来源为已有visual2，不接仿真人物真值。阶段仅导航诊断，裁判原判分和真实连续定位核验分别保存。

city候选启用`SWARM_COMPANION_TRACKING=1`：CURRENT采用自身位置及实际接受视觉序列的速度估计选择约10米观察位置，静止人物保持观察位，运动人物伴随观察。目标位置短时投影只用于导航与朝向，不能写回原图坐标或时间。前向规划候选约9米、预测时域不超过4.5秒，进入既有异步规划/offer/grant；执行仍取实际已提交折线，经雷达、在线地图、友机及双实测速度刹停门。搜索3、追踪2.6米/秒上限保持；速度由跟随误差决定，不能凭配置宣称实际达到。通用默认关闭，原盘旋为兼容回退路径。

视觉接口线格式保持schema2。桥接核心`report`新增明确布尔接收结果；只有本条真实输入被核心接收且轨迹已激活，才转发confirmed_visual和detection。与上一条相同时间不证明本条接收成功；合法不同相机同时间原图仍可转发。该修复不放宽距离、置信度或原图有效期。启动配置可写`bridge_trace.jsonl`，记录实际输入接收结果、融合位置/时间、原图时间、预测时刻及上传请求，日志不参与控制和判分。
