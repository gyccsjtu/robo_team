# 视觉语义 v2.9：同帧衣服颜色核验

schema_version=2字段保持，语义版本从v2.8升级到v2.9。城市入口启用
`PR_COLOR_VERIFY=1`；其他入口默认关闭，可回退到原检测路径。共享GPU与本地回退
必须使用同一个核验器，不改原图、检测框、类别、置信度或坐标，只拒绝颜色不支持的框。

v1.21b实际城市帧证明：蓝衣真人被报成white，棕衣真人被报成green；通用person模型
均能检出这些真人，所以仅添加person核验不能解决颜色错误。新核验仅针对green/white，
读取检测框中央半宽、20%至60%高度的衣服像素。green至少12%绿色，white至少8%白色；
另一种衣服颜色占比达到20%且为本色1.5倍时拒绝。裁剪后少于12像素不作颜色裁决。
这些是本轮实际图像上的开发参数，不冒称官方阈值。红/蓝/棕原检测路径保持。

原图采样时间、逐帧去重与1秒新鲜度检查继续有效，颜色核验不会补造新帧。
真实目标真值只用于独立离线误差分析，不进入核验或运行中的控制。
需验证原有正确绿/白帧仍保留、跨色误报被拦，以及真实六机连续消除。

同轮发现旧感知仲裁将逻辑uav_1..6与Gazebo模型typhoon_h480_0..5比较，始终匹配不上。
城市感知改为复用TaskGate读取`/swarm/authorized_assignment`；同run、同逻辑机号、
新代次/序号且租约未过期的追踪授权才表明本机在随机头跟踪。STOP或过期立即撤销该标记，
不接收旧诊断`/swarm/assignment`作为城市执行授权。该标记只影响视差判决，感知不发布控制。
本机正在追踪的目标在画面居中是正常云台行为，取消原12m以内才豁免“机身附着”的错误距离条件。
其他目标仍保留视差判据，几何/新鲜度/原图去重规则保持。

启动段补修：相机处理循环开始后可收到更新的授权回调，授权标记查询使用查询瞬间的ROS时间；
旧循环时间不等于执行器时间回退，CameraTask读旧时间只返回未知，不能把TaskGate锁成STOP。
此边界回归通过，完整核心414项通过；下一轮才含该修正。
