| 原图时间 | 检测量程/m | 原图坐标与同刻白色真值差/m | 同图人体证明 |
|---|---:|---:|---|
| 1969.844 | 6.882 | 0.09347 | true |
| 1970.496 | 6.646 | 0.23025 | true |
| 1971.836 | 6.824 | 0.09066 | true |

因此不能再说此轮白色没有近距原图，或人体模型对白色全部失明。

实际拦截链：

1. `perception/fresh_person.py:40`：同图人体支持的原图间隔超过 1 秒重置证明计数。三张上述原图在生产类中的计数为 **1→2→1**；最后间隔 1.340 秒。
2. `perception/perception_real.py:867`：track.hits 达到 3 不足以放行。只有 FreshPerson 已取得三张证明才使用三次命中门，否则仍需默认五次。1972.640 秒的实际拒绝：track_id=5、hits=3、person_hits=1、miss=0、current_verified=true，原因 `verdict_hits`。
3. `perception/perception_real.py:1639` 附近：导航候选仅由原判决原因 `range` 触发；`hits/static/self` 不会生成候选。因此这些正确的早期白色检测也不能单靠此通道触发接近或保持视野。
4. `yolo_target_bridge.py:318`：合格观测进入桥以后还要累计 NEW_TRACK_FRAMES=3；超过 COAST_TIME=1.5 秒重新激活。

## 2. 原图准确不代表上传准确

绿色有明确逐级反例：

- 原图 2020.896 秒：uav_4 原始投影误差 0.118134 米，uav_2 为 0.188461 米。
- 同原图的感知输出经过 alpha-beta 滤波，误差变为 0.460258 / 0.603391 米；与 raw 的位置差为 0.556597 / 0.783390 米。
- 桥对两机 0.6 秒窗口内位置做 conf² 加权融合，再对融合位置差分做速度 EMA。上传 2021.892 秒，最新原图年龄 0.996 秒，融合位置时间 2020.661605 秒。
- 日志速度是 `[-0.295618,-0.240348] m/s`；人物从最新原图到上传时却实际移动 `[+1.490667,+1.033394] m`，约 1.814 米。当前低速分支还将外推减半。
- 上传 `[36.581,1.306]`，同刻标签 `[38.985987,2.661753]`，误差 **2.760802 米**。

源码位置：`perception_real.py:781` alpha-beta；`:1910` image_time_position；`camera_geometry.py:5` 非 raw 颜色选择 filtered；`yolo_target_bridge.py:285` 加权位置时间；`:295` 融合差分/EMA；`:397` 低速外推减半；`:409` 外推时长。

结论：这个反例原始框投影已较准，后续滤波残余、混合来源的运动估计及加速/转向响应不足导致上传落后。不是简单“坐标变换错了”。v1.42 来源隔离已针对混合来源，v1.44 针对引导来源；它们没有证明非蓝色滤波和速度补偿已解决。

此轮绿色有109条可对齐桥输入，其中3条原图时刻的输入误差≥1米；124次上传有34次≥1米。两组采样频率不同，不能把比例直接当因果或误差增幅，但逐级反例确实存在。

不能统一删除滤波：本轮棕色 2177.348 秒 raw 误差0.798090米，filtered误差0.471060米；其他样本也有平滑改善。旧蓝色回放 raw+同来源对齐从113/140准确升到131/140，但剩9条仍超1米，最大1.262626米，且属于另一个已明确标记的旧轮。

## 3. 更上游还有两类独立误差

地面投影使用颜色框底部中心作为脚点并假设 z=0（`perception_real.py:1367`）。人体 IoU 和衣服颜色证明不保证框底就是可见脚点；远距接近水平的射线会放大少量像素误差。本轮白色远距原图1960.836/1961.464分别约19.5/18.7米，差1.7145/1.8587米；近距约6.8米则可低于0.1米。此相关性支持距离敏感性，但不能单独确定是哪一个脚点像素或外参误差。

另有 uav_5 原图2000.748秒，white 标签与白色真值相差77.235米，同时人体证明true、IoU0.694946。**人体证明不等于官方白色人物身份或颜色类别正确。** 这个大差值应列为错目标/类别候选，不应算成真实白人定位误差，也不能未看原图就指定它是车、建筑或静态女演员。

## 4. 下一步应改哪里

1. 白色先拆开发现资格与官方三图资格：允许已通过本帧人体/衣服和既有几何、轨迹关联条件的早期证据支持内部保持视野；正式上报继续只由同一原图序列的近距三图建立许可。减少感知资格成立前不向下游传递任何证据所造成的重复等待；桥激活和上报门当前本就并行，不误称它们顺序各攒三张。内部通道必须明确不具备上传许可，先更新候选接口；不直接放宽官方1秒或12米条件。
2. 绿色先针对上述实际转向/加速窗口，回放同来源 raw+近期速度估计与当前 filtered+EMA 对比，选择改善普通运动断点且不伤已有准确段的方案；按颜色启用，不统一删除棕色滤波，不增加固定延迟常数。
3. 原图脚点/姿态误差与错目标分开取证。以实际近距原图核对底部落点；不凭高颜色置信度或高人体IoU豁免身份。取得明确反例再修投影或身份门，不能用真值喂控制。

这是根因分析与修复方向，不是上述新策略已实现。当前v1.44候选没有新的实体效果证明。
