# 执行器停止保持 v1（2026-10-03 冻结）

run17后半段命令水平速度已为0，但实测位置仍缓慢漂向建筑，最终uav_6发生机体接触。零速度流不能作为位置保持完成的证明。实际执行器改为单一setpoint_raw/local发布者：正常移动用ENU水平速度与垂直速度；安全层最终要求停止时，锁定首次停止时刻的实际MAVROS局部XY，由PX4位置环保持该锚点，垂直速度和偏航率仍走原护栏。

消息使用标准mavros_msgs/PositionTarget，coordinate_frame=FRAME_LOCAL_NED（MAVROS薄层转换ENU）；移动mask=1479，停止XY位置+Vz mask=1500。停止锚点不会随每帧位姿漂移更新；下一次完整安全门放行非零水平速度时撤销。初次没有有效位姿时只发送零水平速度，不猜锚点。检测到局部坐标原点变换时只能以当前有效局部位姿重新进入停止保持，不能将旧局部锚点直接复用。

该保持是获准运动的制动/停止动作，不是让行路径或新目标授权。STOP/租约到期/缺雷达时仍须实测连续停稳，不能凭发布位置设定点释放占用。旧速度话题不再同时发布，外围若订阅该话题作统计须迁移到raw或控制CSV。兼容边界：ROS SearchAssignment、任务schema2及路线schema1不变；飞控执行话题变化需整轮重启，不能仅热切一架。

run18已在开发六箱场景实测120.216s：最小箱体距离1.53085m、机间距6.7710m，无机体碰箱。结果及执行源码见validation/six_obstacles_run18。该保持仍不声明三维起降安全或正式比赛通过；后续改变执行配置或环境需重新验证。
