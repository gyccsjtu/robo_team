# 最终方案：los_safe（--space los）

## 一句话

**`--space los` = SEP=3 + SEARCH_PHASE=6 + FRIEND_SAFE=3 + LOS 保持排斥，是当前最优。**

多机**非编队协同 + 每机独立规划 + 3m 防碰撞 + 建筑避障 + LOS 感知 + 15s 连续确认**，
而不是固定队形。

|---|---|---|---|

## 核心逻辑

1. **编组几何 SEP=3**：同目标 tracker 角度分离（弦长反解 Δθ=2·asin(SEP/2r)），
   只在真要撞上时让位。
2. **搜索相位 SEARCH_PHASE=6**：相邻带蛇形相位错开，搜索机不共线。
3. **局部排斥 FRIEND_SAFE=3**：速度层排斥，**推开后必须保持目标 LOS + 落点
   必须 free**，否则换方向或拒绝推开。

## 关键决策（用户确认）

- **硬约束**：不撞建筑、不撞其他无人机 → 碰撞事件计数（进入区间计 1 次）
- **优化目标**：保持 LOS、保持感知、15s 连续确认率、目标消除率
- **不用 ≥3m 作硬约束**（3m 是参考值，实际以碰撞几何为准）
- **LOS 断开 → 15s 计时清零 = 失败**，不改成累计

## 撞建筑 bug 的修法

v1 在「推开破坏 LOS」时拒绝推开 → 机为保 LOS 撞进建筑（116 次）。
v2 加了两道 free 检查：推开落点必须 free、偏转候选必须 free → 建筑碰撞归零。
