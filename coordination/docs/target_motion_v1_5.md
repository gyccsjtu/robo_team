# 原图运动估计与追逃速度 v1.5

生产confirmed_visual_observation回调原来固定目标vx/vy=0、state=0，追逃判断
不会触发。在线盘旋与下游自适应速度还会将任何追逃请求重新压到1.5m/s。
该执行速度小于规则规定的2m/s逃跑速度，无法持续跟随。

现在按目标和相机分开保存最近1.5秒原图测量，以线性拟合估计速度。
至少3个测量、0.5秒跨度，连续两次速度达到1.6m/s才标记估计的快速运动。
超过1秒的观测缺口或超过3m/s的拟合跳变清空运动累积；跨相机不直接差分。
不增加消息字段，不预测新观测，不刷新sample_s。state只表示视觉估计模式，
不是读取官方演员状态。

城市追逃速度设为2.6m/s，仍受3m/s总限速、雷达/机间/路线/观察空间检查约束。
在线盘旋和下游自适应限速保留该追逃速度，普通盘旋仍沿用1.5m/s。
追逃估计按原图时间失效。该修复尚需下一轮实体任务验证；噪声或转弯可能导致
误判或暂时漏判快速运动，不能把实现或单测通过当作完整六目标比赛验收。
