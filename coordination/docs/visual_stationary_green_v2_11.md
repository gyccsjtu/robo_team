# 视觉语义 v2.11：有效追踪中的同帧绿色人体

冻结语义修订，继承 v2.10。对外仍用 schema_version=2 原图视觉证据，
城市入口仅在 `CITY_EXPERIMENTAL_V123=1` 时启用；默认保留已成功的v2.9行为。
不改变 target_id、xyz、confidence、sample_s、授权或锁字段。接收端兼容。

v1.22b 原始记录里，绿色正确坐标的上报被 verdict_static 拦下：人物在
障碍边停住，不等于目标消失。只读真值用于离线核查，不能进入本修复。

仅在以下条件同时满足时，绿色不再需要“正在运动”才能上报：

- 当前逻辑飞机持有同 run 有效的 t0 追踪授权；STOP、过期或其他任务不满足。
- 当前检测框在这一张原图通过 COCO 人体重叠过滤与绿色衣服核验。
- 衣服裁剪足以判断颜色；小框或未知颜色证据不获得豁免。
- 轨迹本帧命中、原图时间有效且不超过 1 秒；重复帧仍不产生新证据。

人体/身高、量程、关联命中数及置信度等其他检查继续执行。蓝色静态人物
不获得该豁免。豁免不延长 coast，不补造位置、不刷新原图时间。

共享推理 JSON 回复新增可选字段 verification_version=1 与
verified_green_person（布尔值）。成功完成同帧过滤且绿色人体过滤、衣服核验
均开启时才为 true。客户端仍自行核查其原图绿色衣服裁剪。
旧客户端忽略这些字段；新版客户端连接旧服务时缺字段默认 false，保持原运动过滤。
本地回退使用同一个 PersonVerifier 判定配置，并对同一原图核查颜色。

成功六机运行使用 v2.9 启动快照，不热改；候选仅显式开启后进入新快照。
尚需真实六机验收，不能以离线回放或单测替代六目标完成。
