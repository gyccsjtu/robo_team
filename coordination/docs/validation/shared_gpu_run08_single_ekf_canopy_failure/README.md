# 单EKF六机轮08：顶棚碰撞复现

运行301.536仿真秒，最高实际高度4.344350m；仅actor_4消除，剩余5个目标。六机启动参数读回通过。原生机体接触在2148.828s记录1号机碰撞gas_station_73，之后PX4出现失控保护和无效setpoint，单EKF不能修复二维激光漏扫顶棚的物理问题。原始裁判、PX4、轨迹和中断结果保留；此轮碰撞失败，不是正式比赛通过。

5号机停在(-24,5)附近。stuck_map_uav5.json包含只读真实scan和在线地图：最近雷达回波1.584m，被0.5m栅格量化到距当前位置1.319m的占据格。使用同一scan、近同时刻yaw和假设已有近盲区证书进行分辨率比较：0.5m起点阻塞，0.25m起点可行，保护半径均1.2m。假设近盲区证书仅用于隔离量化因素，不证明现场证书仍有效。grid_quantization_probe.json记录限制和耗时（0.25m构建约0.484墙钟秒）。

下一轮试验合并巡航3.0m(v1.13)和在线地图0.25m(v1.14)，维持既有雷达制动半径、路线净空和机间距离。核心370项测试通过；尚需真实六机证明解卡、不碰顶棚及六目标消除。

绿色没有本轮正例；蓝色上报与同时间真值存在约142m差异，不能因图中可见人形而取消运动判决。原始精度数据保留。
