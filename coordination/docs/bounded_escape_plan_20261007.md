# 起点卡住后的有界退出候选计划

第三轮2号机真实停住，近期命中落在1.2米规划膨胀包络内；换目标仍不能规划。原始模型base碰撞盒0.67×0.67×0.15米，旋翼中心约0.243米、碰撞半径0.128米，现有路线机体包络0.7米大于这些碰撞几何的平面外延。这只是当前开发机型证据，不是正式模型或三维避障证明。

不统一降低正常规划半径。拟增加仅限搜索任务的退出模式：正常半径仍1.2米，退出规划暂用0.9米（仍包含0.7米机体包络），最大退出长度2米、最终速度上限0.3米/秒；现有雷达保护半径1.2米和双来源实测制动仍保留。退出先要求两来源新鲜三维速度连续1秒不超过0.15米/秒，定位可用、当前任务授权有效。

路径必须从实际起点开始，使用当前已观测且连通的退出网格，不能填未知或挪起点。退出终点必须在原1.2米正常网格中自由；每段持续远离造成起点阻塞的近期命中。双方网格须同一尺寸/分辨率/原点，退出网格仍经过现有友机及保留通道排除。未找到符合条件的连接时保持XYZ停止。模式须绑定实际offer/grant和代次；STOP、过期、重规划取消不留下例外。每代次最多一次退出，不能无限重复绕过正常门。

分两步：先实现纯Python退出路径选择和必要边界；再接入在线地图快照、实测停稳、offer/grant、最终速度及高度保持，更新兼容说明并整体检查。仅纯函数通过不能称卡点已经修好，不开启新仿真。原运行旧快照继续收集视觉和搜索证据。

若回放证明0.9米网格起点仍未知/占用，不用猜测补证，保持拒绝并记录缺失输入。新增恢复只是局部开发策略，不完成完整三维盲区、正式相机/模型/出生布局兼容。
