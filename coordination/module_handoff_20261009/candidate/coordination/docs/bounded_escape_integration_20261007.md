# 搜索卡点有界退出：接入候选

基于fb0df4e继续实现，未启动新仿真。第三轮实体执行e83839b、600秒约1/6、非地面接触0；本候选的连片搜索和退出模式均不能借用该轮作为实体效果证明。

## 已接入

- agent在现有权威状态发布循环中维护双来源实际停稳资格；仅搜索任务、已起飞、定位可用、变换/地图epoch一致、原始消息新鲜且上次水平指令为零时可以累计。
- 正常规划报告START_CLEARANCE_UNKNOWN时尝试同观测的0.9米退出网格，正常1.2米网格和友机/保留通道排除保持。较小网格仍未知或占用则不提出路径。后台生成proposal后，当前实际位置至整个退出路径重新检查净空、持续远离阻塞回波和总长2米。
- proposal不是放行。实际RouteGate验证schema1的offer/grant、代次、points、时效后，再复验停稳、扫描年龄0..1.5秒、坐标变换和实际位置连接。有效授予才消费该代次的一次退出机会。正常路线授权不使用退出网格。
- 有效退出期间搜索刷新不取消已提交路径，也不进入搜索观察状态。控制引导来自已授权退出路径，最终经过原雷达、友机、路线门和当前扫描的双来源实测制动。水平指令在加速度及友机修改后仍不超过0.3米/秒且不朝原阻塞命中运动。
- 记录接受自身位姿样本的累计水平运动，最多2米；执行最长15秒。续约不能重置距离、开始时间或代次额度。距离为离散位姿折线长度，不是连续真实轨迹保证。
- 移动时通过PositionTarget的PZ保持授予时局部高度；停控仍XYZ保持。显式升降与限高/坠地恢复指令优先。STOP、授权到期、新代次、定位/epoch/变换异常、倒退时间或执行预算耗尽撤销退出例外，并保持manager占用退役语义。
- 到实际终点0.15米以内且当前正常1.2米包络恢复净空后，停止退出、下一拍继续原搜索任务。这不等于已完成搜索点观察。

## 接入与回退

路线接口兼容修订v1.4，线上仍schema1，不增加manager授权字段。六agent必须统一包含swarm_agent.py、bounded_escape.py、online_radar_planner.py及position_brake.py的新快照。city_swarm_run.py默认开启，可用CITY_BOUNDED_ESCAPE=0关闭；通用agent默认关闭。city_control_config记录启用状态和门限，导航schema1可选bounded_escape只用于诊断。

## 验证与未解决项

新增测试直接执行当前agent的规划线程、实际RouteGate、grant回调、控制方法和PositionBrake，覆盖无grant不放行、延迟/错代次/错points/停稳丢失/位置漂移拒绝、友机改向后限速、保持高度、STOP回调、到期、定位/epoch异常、实测距离耗尽、续约不重置、原命中被新扫描覆盖仍停车和同代次仅一次。测试的姿态/速度输入是构造夹具，ROS时间/发布和雷达/友机输入部分替身；不等于完整ROS回调时序或实体制动效果。

尚需用第三轮扫描历史离线检查实际卡点是否存在0.9米已观测通道。若仍没有通道，不能通过填未知、挪起点或降雷达半径制造退出。随后才验证统一快照的真实六机运动。本候选不解决所有人物误认、持续15秒定位、三维盲区或正式环境兼容，比赛目标仍未完成。
