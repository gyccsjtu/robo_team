## 没有盲目修改框底系数

对两轮真实相机位姿、框及实际演员位置离线重放，将现有 5% 框底内缩直接
改成 0 或 2% 均使多数目标误差变大。例如本轮 3 号机棕色 409 个完整框，
0%、2%、5% 的误差中位数约 1.133、1.050、0.922 米。
这不证明 5% 对所有画面最优，但明确否定了“直接取消内缩就能修好”的猜测。
没有将离线真值或拟合系数反馈给飞行算法。

## 双机视觉交叉定位值得进入下一批

离线原型使用两个相机的真实图像时刻、机载估计相机位姿和人物框中心射线。
仅时间差 ≤0.15 秒、射线夹角正弦 ≥sin(25°)、正向交点距离 3–20 米、
交点与两路原定位都不超过 3 米时，比较水平视线交点。
这是传感器几何方法，不要求官方位置作为算法输入。
