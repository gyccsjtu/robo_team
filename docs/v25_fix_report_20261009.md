## 二、v25 修复清单（5 项，全部落盘 + py_compile + lint 通过）

### 修复 1（核心）：搜索巡航恒速提速 1.7 → 3.0 m/s
`swarm_agent.py` 搜索分支：

```python
# 旧：vx = POS_KP * err（LOOKAHEAD=3m 理论 2.4m/s，实际 ~1.7m/s）
# 新：
_err = math.hypot(err_x, err_y)
if _err > SEARCH_DECEL_M:              # 远距引导点 → 恒速巡航
    vx = err_x / _err * SEARCH_CRUISE_SPEED   # 3.0 m/s
    vy = err_y / _err * SEARCH_CRUISE_SPEED
else:                                  # 近引导点 → 切回 P 控制自然减速
    vx = POS_KP * err_x
    vy = POS_KP * err_y
```
- `SEARCH_CRUISE_SPEED=3.0`（env 可调）、`SEARCH_DECEL_M=2.0`（减速带）
- 安全性：v23 重定标确认**未武装目标不会逃**（逃跑=一次性闩锁，需 reported），搜索段全速安全；已武装目标 22m 内由 `_transit_cap=0.85` 压速兜底；"播报闸门 9.5m + CLOSE_ENOUGH_M=11m"保证武装瞬间机速已 <1.0m/s

### 修复 2：雷达守卫去掉无近障时的 0.65 硬上限
`swarm_agent.py`：`forward = min(speed*0.65, ...)`（把 3.0 压到 1.95，抵消提速）→ `forward = min(speed, ...)`，**保留 front<5.5m 的近墙线性减速段不变**（front=3m→1.8m/s、front=1.6m→0，刹停距离仍 < LOOKAHEAD=3m）。
- 依据：v16 设 0.65 时巡航只有 1.7m/s（无影响），现在必须去掉才能让提速真正生效

### 修复 3：EARLY_PHASE_SEC 90 → 30

- v12d 时代设计（90s 蹲守 spawn 区找 actor_4/5）已失效——actor_4/5 出生即跑，蹲守找不到
