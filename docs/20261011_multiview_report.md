# 双机视觉上报：分阶段验证

上一轮棕色、白色长期被看见仍反复重新识别。两机同看一个演员时，不同相机的
单目地面投影具有不同偏差；单机来源保持机制会把其中一条偏差持续报给裁判。

本批为合格完整人物框附加图像时刻相机水平射线，不改变官方 ActorInfo 接口。
桥接完成原有物理实例关联后，积累两个不同相机的交点；来源/候选切换不共用
历史，重复帧不能贡献新证据。时间差不超过 0.15 秒、夹角正弦不低于 sin(25°)、
正向距离 3–20 米、与原定位相差不超过 3 米时才构造交点。

正式出口仍先经过原单机有效期检查。双机交点至少三对独立图像、跨度至少
0.7 秒，经现有稳健运动拟合通过，且两张最新图片均不超过 0.35 秒，才可替换
此次坐标；改变量不超过 1.5 米。否则保留原单机结果，不能增加断流或延长预测。
单机轨迹、控制和任务分配仍用原方法，不把交点混进带偏差的历史。
当前只处理四个不同颜色目标，红色两个身份仍沿用已验证的原链路。

开关 `BRIDGE_MULTIVIEW_REPORT=1`；初始默认关闭，供本批 GUI 验证显式开启。
日志 `REPORT_POINT method=two_camera` 和队内 report_telemetry 的 position_method
记录真实使用情况。正式算法不接收演员真值或裁判状态。

## 离线验收

`tools/replay_multiview_reports.py` 使用保存的 visual_source 做身份关联、实际图像
和机载相机位姿生成射线，在历史真实上报时刻计算修正。算法选择完成以后才用
独立真值文件评分。没有原型中“原坐标距离真值不超过 3 米”的筛选条件。
该回放不能模拟新的飞行路线或旧记录没有保存的候选回调，因此不是比赛结果。

485 秒那轮：棕色 188 条报告中超差由 51 降至 49，白色 130 条由 26 降至 22；
蓝色 20、绿色 0 次超差不变，没有新增超差。
最终 41 次替换，其中 39 次有有效真值时间括区，其余 2 次没有可评分真值。
初版允许 0.6 秒双机预测时新增一次棕色 0.974→1.015 米超差；该反例促使
收紧组合观测时限，已经保留测试，不能把它从旧结果中隐去。

337 秒那轮没有合适配对，全部历史输出不变。该轮 39 条错误蓝色候选仍保留
在评分里；双机几何不能解决雕塑身份问题。辅助分类器会误伤白衣演员，未部署。

614 项测试通过，启动检查通过。比赛提速及 180 秒目标尚待 GUI 验证，不能
用离线误差减少宣称连续 15 秒确认或 6/6 时间已经改善。
