# 雕塑识别与实例身份修复

## 原始证据与边界

`da2cd1c` 的 `logs/logs_20261011_111144` 官方 6/6，538.332 秒、2036.5 分。
比前一轮 `db37fb1` 的 462.716 秒慢 75.616 秒。正式结束时间与 43 份源码已保存
在 `artifacts/verified_6of6_20261011_111144/`；读取真值的开发诊断不进入正式算法。

旧代码断流超过 1.5 秒允许蓝色槽直接跨地点移动，但没有触发假设切换事件。
西侧疑似雕塑两次累计占用主追约 190 秒，东侧新发现与旧负责人不同步；此前
仅修成熟静止轨的替代路径，没有覆盖这个入口。本轮显式 HYPOTHESIS 事件为零。
蓝色消除前约 15 秒约 95% 时间静止，棕色同期约移动 15 米。不能把最后 6/6
当成各色移动跟踪已经可靠，更不能把静止当作雕塑的分类依据。

## 候选链路批次

- `/coordination/target_report` 与 discovery 使用 schema 2 整帧候选数组，保留
  旧单条输入。实例 ID 为感知进程 UUID 加本地轨迹 ID；官方 ActorInfo 不变。
- 同帧先接收完整候选集合再仲裁。来源、时间与重复 ID 严格验证；同色异物体
  不共用运动拟合、官方来源或新观测计数。ambiguous 仅进入限时补看。
- 所有异地重获入口统一经过六张独立合格图像、跨度至少一秒、间隔最多 0.6 秒
  的一致性检查。历史窗三秒支持实际 2 Hz。旧合格源已失联两秒时不再等 35 秒；
  正常有效主追仍受保护。远处换槽同步通知调度与控制，旧位置暂缓 25 秒。
- 同机多个同色实例、新相机附近的同色实例分别保存。已验证主实例优先；
  新实例不能单凭更高分数覆盖正在积累的目标，也不能用 discovery 降级合格图像。
- 失败退避保存来源和实例 ID。跨色只有非常接近的失败地点共享有限冷却；
  同帧确实可区分的两个物体不互相冷却。换 ID、重叠框、不同帧不能伪造豁免。
- tracking_view 额外携带 world_candidate_id；相机绑定到合格实例，切换时清除
  旧图像、高度修正和补看。像素短时续锁保留世界实例，不产生位置或上报资格。
- 正式人物资格不依赖是否移动，保留原定位、身高、附着伪框、置信度与图像几何
  门。干扰类冲突仅在同物体严格重合且连续证据充分时裁决，其他情况限时补看；
  不使用全局跨类 NMS，不把邻近演员连带删除。

本批不修改飞行速度、官方人物、裁判、地图、出生点或传感器参数。旧五类 v1
仍可能识别雕塑；候选隔离不能替代六类模型训练。新权重未验收前不自动替换。

## 六类训练与数据审核

保留原五色，添加 `distractor_person`。原数据 792 train、340 val 不混合重分；
114 张通用背景负图不能替代雕塑专门采样。新增图像来自隔离训练场景原生相机，
官方源码文件不改动，没有正式飞控、调度或裁判节点。布局整体划分 train/val/test。
旧模型框仅用于提议，须经视检修正；未审核、漏框、严重遮挡图不作为空标签负图。
用户可在本地 HTML 页核查并导出标注，用户反馈和助手视检分别记录。

训练使用独立 Python 环境，解决 RTX 5060 与系统 torch CUDA 内核不兼容，
不升级 ROS Python。v1 微调，640 输入，最多 60 epochs，patience 12，batch 8，
显存不足降为 4。训练产物必须在正式系统 Python/CPU 实际加载并推理后才可接入。

权重验收：独立图像比较 v1/v2/六类候选的各色召回与雕塑误检；每色召回相对
v1 不降超过一个百分点；再验证整段视频不形成雕塑持续跟踪任务。小样本不能
替代未见场景和动态全链验证。后续仍需移动蓝/白连续准确上报及三轮官方 6/6。
