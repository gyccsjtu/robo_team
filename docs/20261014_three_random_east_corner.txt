This commit adds a bounded east-corner check to ordinary segment allocation.
It selects only an already eastern idle aircraft with fresh processed-camera
geometry, checks a collision-free inner viewpoint/path to one of the two
actual actor-area corners, and credits the corner only after real processed
images. A current person view, tracking task, stale camera, blocked endpoint,
or already recent corner image prevents diversion. It never publishes actor
commands or uses actor truth. It does not alter formal reporting/YOLO/official
code. EAST_CORNER_CHECK=0 disables the addition; selected stable wrapper uses 1.
