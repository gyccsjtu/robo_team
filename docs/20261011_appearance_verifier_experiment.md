# 外观复核试验：禁止部署当前 v3 last 权重

独立工作区 `/tmp/robocup_appearance_verifier`，不影响 `main` 的正式感知。
`PR_APPEARANCE_WEIGHTS` 默认空；只有显式设置才加载第二个完整画面检测模型。
保留 v1 的框、颜色和置信度，仅将相同物体的负外观证据标成疑似或干扰。
两模型分数不直接比较，使用复核模型内部的 actor / distractor 差值。
匹配必须唯一，禁止旁边的真人继承干扰判决。疑似候选仍允许短时补看。

0.50 以上的明确负证据进入疑似；三个独立图像、跨度至少 0.30 秒、每帧负类
置信度至少 0.75 才判干扰；复核模型内部负类差值至少 0.20。时间倒序、
重复图像和长间隔不能累积确认。独立分支全量 610 项自动检查通过。

## 实际试验及失败依据

1. 从 v1 框裁剪、交给 v3 last 复核：原验证召回不降，但既有 D10 中的
   3 张雕塑误检一张也没挡住。不能将零真人误拒等同于有效治理。
2. 完整画面、负类 0.75 门槛：原验证召回不降，D10 的 3 张误检挡住 2 张。
3. 按上述“疑似 / 干扰”分级实现：原 340+34 负图+B8 召回保持；已看过的
   D10 参考组五色仍各 10/10，3 张雕塑误检全部被阻止直接上报。
   D10 不是新盲测，设计过程已查看这些图，不能用它宣称泛化成功。
4. 对本次自然飞行新采集的 409 张图作反事实检查，有 5 张触发了疑似。
   助手逐图查看后确认：五张全部是真实白衣演员，不能部署此权重。

具体图片位于 `/home/gycc/robocup_distractor_data/flight_57f3690/`：
`0228_typhoon_h480_0.png`、`0250_typhoon_h480_0.png`、
`0298_typhoon_h480_3.png`、`0306_typhoon_h480_0.png`、
`0327_typhoon_h480_3.png`。复核模型负类置信度约 0.605、0.708、
0.606、0.796、0.828；其中最高者同时还有 0.557 的演员预测，仍通过负类差值。
这些帧未加入训练，未作为用户审核标签；其余 404 张无触发，也没有被自动
标成人工审核完毕。新增画面未提供完整 GT，不能计算整体真人召回。

这是运行环境泛化失败，不能靠单纯抬高阈值或把这五张图调到通过来宣称修好。
后续需要更多灰白衣、背面和远处小人训练图，独立场景验收，并检测整段视频
是否中断真人上报。此分支只保存实现和失败证据，不合入正式比赛版本。
